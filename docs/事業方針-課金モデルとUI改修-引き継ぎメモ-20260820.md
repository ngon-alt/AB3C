## 2. 観測された事実（推測を含まない）

### 2-1. 診断は価値が実証されている
- **フューチャーショップ社**：診断100本分を購入。リスティング広告で商談1件あたり数万円かかるため、診断でリード獲得率が上がるなら安いという評価。見込み客へのばらまきに使用。
- **Webコンサルタント（professor氏）**：10診断分のライセンスを購入。数本を顧客に投げたところ翌日にポジティブな反応。コストパフォーマンスが良いとの評価。
- **合宿参加コンサルタント**：自社顧客に診断を実施、強い興味を得たとの報告。

→ 支援者チャネルにおいて、診断は**リード獲得ツール**として機能している。

### 2-2. 戦略チャットは「自分の事業を分析する人」に使われている
- 合宿で自社分析をした経営者は戦略策定チャットを多用し、高い評価。
- 代理店・支援者が深く使う例は少ない。

### 2-3. 戦略アクション（10テーマ）の利用者は実質ゼロ
- 有料ユーザーでアクション機能まで到達している例がない。
- 無料お試しユーザーのアクション利用状況は**未計測・不明**。

### 2-4. 想定と実態のズレ
- 当初想定：経営参謀として毎日大量に対話するユーザー
- 実態：**戦略指南AIの通常ユーザーとして入った層**は、ほぼ診断のみの利用。日常的なヘビーユースは発生していない

### 2-5. ただし例外がある：新規事業立案者は極めて相性が良い（重要）
AIサービス開発研修の参加者（＝AIを使った新規事業を立ち上げようとしている層）は、実態が大きく異なる。

- **戦略立案画面のチャットをヘビーユースしている。**かなり作り込んで戦略立案を行っている
- ある程度事業の形ができた段階で、**SEOやサイト構築などのアクション機能を使っている参加者もかなりいる**

→ 「戦略が固まっていない、これから事業を作る人」には本体機能（戦略立案チャット＋アクション）が刺さる。
→ 既存事業を持ち、既に自分なりの戦略が固まっている経営者ほど、診断だけで止まる傾向がある。

**これは顧客像を考えるうえで最も重要な発見のひとつ。**
「経営者か代理店か」という軸だけでなく、**「これから事業を作るか、既にある事業を回しているか」という軸**で利用深度が分かれている可能性がある。新規事業立案フェーズにいる人は、そもそも言語化すべきことが未確定なので、対話で詰める必然性がある。

## 3. 顧客像の構造的整理（重要）

支援者と経営者では、ビジネスモデルが根本的に異なる。

### 代理店・支援者チャネル
- 世の中の「コンサルタント」を称する人の多くは、**制作物（Webサイト等）を売っており、抽象的な戦略・アイデアそのものに課金できていない**。コンサルティングは制作を売るための無償の営業活動として提供されている。
- したがって彼らにとって診断は**商品ではなく営業装置**。
- 戦略チャットやアクション成果物を渡しても、それを売る先がない（クライアントの採用・プレスリリース等を引き受けたい代理店は少ない）。
- **仮説：代理店向けには診断が完成形であり、それ以上深くする必要がない可能性が高い。**

### 経営者チャネル
- 単体で戦略を渡されても活用できない（戦略に沿ったマーケティングという概念、Web、補助金などが理解されていない）。これが従来の利用率低迷の主因と考えられる。
- しかし**伴走・教育とセットなら本体機能が刺さる**（合宿参加者の反応が根拠）。
- **仮説：経営者向け本体機能は、教育・伴走とのパッケージでなければ成立しない。逆にセットなら成立する。**

### ミッションとの整合
ゴンウェブ／デジ革のミッション「リーダーを支える、リーダーを育てる」に照らすと、
代理店＝支える対象、経営者＝育てる対象。両輪であること自体は方針と矛盾しない。

### 想定される連結構造（仮説）
代理店が診断をばらまいて経営者を掘り起こす → 掘り起こされた経営者のうち自分で戦略を持ちたい層が教育事業に入る。
代理店に無理にコンサルティングを売らせず、彼らの得意分野（制作を売る）のままリードが流れる構造。

## 4. 課金モデルの方針

### 4-1. 変更の目的（ここは確定・ぶれさせないこと）
固定パッケージ価格から、**課金単位を細分化したハイブリッドモデル**（基本料＋一定枠＋超過分はポイント消費）へ移行する。

目的は**値下げではない**。
- 完全固定パッケージは「使うかどうか分からないものに大きく賭けろ」と要求する。利用実績のない現状では最も相性が悪い。
- 課金の流動性を高め、最初に躊躇する層に「自分に合った程度の課金」を提供して利用を生む。
- 副次的に、月額固定では取れていなかったヘビーユーザーからの収益上限が外れる。

**注意：これは値下げか値上げか一概に言えない。少量利用者には値下げ、大量利用者には値上げになり得る。結果は顧客ポートフォリオ次第であり、走らせてみないと分からない。**

### 4-2. 原価の位置づけ
- 原価はおそらく制約になっていない（診断1本の推定原価は売価7,700円に対して数%程度）。
- ただし**実測値はClaude Code側で確認すべき**。確認項目：
  - 診断1本あたりのAPI呼び出し回数・使用モデル・input/outputトークン数
  - 戦略チャット1ターンあたりの同様の数値（履歴累積があるためターン数別に）
  - アクション成果物1本あたりの同様の数値
- 原価が制約でない以上、**ポイント単価は原価ではなく顧客が感じる価値と競合比較で決める**。
- 参考：診断¥7,700が「リスティングの数万円より安い」と評価されている。その先の一歩を数百円〜1,000円台で刻むのは価値の連続性として妥当。**1チャット100円は安すぎて価値を毀損するリスクがある。**

### 4-3. 課金単位について

**用語の確認：検討中の「1チャット」は1ターン（1往復）を指す。セッション単位ではない。**

**案1：ターン課金（案として保持）**
- 1ターンごとにポイント消費
- 問題点：履歴を毎回送るため、セッションが長くなるほど1ターンあたりの実原価が上昇する。原価と課金額が乖離していく
- 緩和策の候補：一定ターン数ごとに履歴を要約して圧縮する、長いセッションでは消費ポイントを段階的に増やす、など。ただし後者はユーザー体験を損なう
- 新規事業立案者のようなヘビーユーザーからは収益が取れる（現行の月額固定では取り漏らしている層）

**案2：成果物単位（診断1本、チラシ1本、求人資料1本 等）**
- 何にいくら払うかが自明で、ユーザーが理解しやすい
- 原価とも価値とも一致する
- チャットは成果物に付帯する道具として開放できる
- ただし、新規事業立案者のような「対話そのものに価値を感じている層」からは収益を取りこぼす

**評価**：どちらも一長一短。2-5の発見（新規事業立案者は対話をヘビーユースする）を踏まえると、対話に一切課金しない設計は収益機会を逃す可能性がある。**両者の併用（成果物は成果物単位、対話は枠＋超過ターン課金）も選択肢として検討する。**

### 4-4. 枠の設計
- 現時点でユーザー数が少なく、統計的に有意なチャット回数分布は取れない。**計算で初期値を決めることはできない。**
- したがって**枠は「後から動かす前提の可変パラメータ」として実装すること**。
  - 枠の回数をコードや価格表に固定的に埋め込まない（管理画面から変更可能な値として保持）
  - 既存契約者に影響を出さずに枠のみ変更できる設計
  - 表記は「◯回まで」より「標準的な使い方で1ヶ月分」寄りにしておくと後で動かしやすい
- **初期値は広めに置く**こと。狭くして超過が頻発すると「使うと減る」心理で利用そのものが止まり、現状で最も避けたい事態になる。広く置いて誰も超えなければ実質定額として機能するだけで損失はない。
- 超過ポイントの単価は基本料換算の倍程度が妥当（定額側への誘導圧力になる）。
- **繰越の可否を決める必要あり**（未決定）。

## 5. 開発に反映すべき具体項目

### 優先度A：アクション機能のUI改修
現状は「診断 → アクションに移動 → テーマを選ぶ → チャットで指示」の3段構えで、各段で離脱している可能性が高い。

**改修案：診断レポート生成直後に、各アクション成果物をカード一覧として並べる。**
- 「営業チラシの資料があります」「求人資料があります」等が最初から見えている状態
- 押した瞬間に生成して開く（全カード同時生成は原価が跳ねるため、オンデマンド生成を維持）
- **カード上にAB3C分析から取れる中身の一片を表示する**（チラシならキャッチコピー案、求人なら訴求文の冒頭など）。タイトルだけでは機能名にしか見えず押されない。この一片は診断時に一括生成しておく
- チャットは入口ではなく出口に移す。まず完成品が1枚出て、その後「もっと堅い調子で」等の調整のみチャットで行う

**課金との接続**：カード表示は無料、開く（生成する）とポイント消費。これにより従量課金の単位が自然に「成果物1本」になる。

**注意：この改修が利用率を上げるかどうかは検証されていない仮説である。** ただし「能力を要求しないUIにする」という方向自体は、観測されている実態（チャットのハードルが高い、活用能力が壁）と整合する。

### 優先度A：計測の実装
現状、アクション機能が使われない理由が特定できていない。以下を計測すれば、原因が3つのどれか判別できる。
- アクションのテーマ別クリック数
- テーマ別のチャット送信回数
- 戦略確定まで到達したユーザー数

判別:
- テーマ選択画面まで来ていない → 導線の問題
- テーマは選ぶが1ターンで離脱 → 「何を書けばいいか」の問題（カードUI改修が効く）
- 戦略確定に到達していない → 3段階が長すぎる、アクション以前の問題

既存の履歴がDBに残っていれば、集計するだけで判明する可能性がある。**まずDBの既存ログで算出できないか確認すること。**

### 優先度B：ホワイトラベル対応
代理店にとって診断が「自社の営業装置」である以上、自社ブランドで配布できることは価値になる。

- ロゴ差し替え、CTA埋め込み、配布元へのリード情報（メールアドレス等）の還流
- **2段階の価格設計を検討**：
  - 準ホワイトラベル：ロゴは差し替え可、「Powered by AB3C」等の出典表記は残す（AB3C普及と教育事業への導線を保持）
  - 完全ホワイトラベル：AB3C表記も消える。高価格
- **論点**：完全ホワイトラベルはAB3C普及という目的と部分的に相反し、掘り起こした経営者が権さん側に流れてくる導線も切れる。「ブランドを消す権利にいくら払うか」という値付けの問題として整理する。

### 優先度B：無料お試し（24時間）の再設計
- 診断 → 戦略を固める → アクションを試す、を24時間でやり切れる人はほとんどいない。**アクションは構造的に試用期間内に到達しない可能性がある。**
- カードUI改修（優先度A）が入れば、診断直後にアクションに到達できるため、24時間でも機能する可能性が高まる。
- 期間延長の是非は別途判断。

### 優先度C：アクション10テーマの絞り込み
10テーマ（SEO／SNS／Web広告／Googleマップ／チラシ・DM／プレスリリース／ウェブサイト改善／採用コンテンツ／補助金申請／営業資料）を並べたことで「どれも自分向けではない」に見えている可能性がある。

- 代理店向けビューでは、**代理店自身が納品物として売れるテーマ**に絞る（ウェブサイト改善、営業資料・提案書、SEO 等）
- 採用・プレスリリース等は経営者向けビューに寄せる
- ※これは仮説であり、優先度Aの計測結果を見てから判断してよい

## 6. 未決定・9月末に判断すること

### 最大の分岐点：合宿参加者の継続利用
- 現在（〜2026年9月末）は研修期間中でフル機能を提供中
- **観測すべきは1点：経営者が戦略チャットの先（アクション）まで進むか**
  - 進む → 「教育・伴走とセットなら経営者向け本体機能は成立する」仮説が立つ。経営者向けラインを教育とのパッケージ商品として設計する
  - 診断だけで止まる → 伴走があっても本体機能は使われないという厳しい結論。代理店向け診断＋ホワイトラベルに集中する
- **経営者向けラインの価格確定は、この結果を見てからでよい**

### 決めきれていない事項
- Customer：経営者本人か支援者か（両輪でいくとして、商品構成をどう分けるか）
- 繰越の可否
- 経営者向け廉価ライン（¥3,000/¥10,000/¥30,000構想）の扱い
  - **警告：もし現行のサブスク価格体系を残したまま廉価ラインを追加する場合、深刻なカニバリが発生する。**廉価ラインで複数サイトを許すと、現行15サイト¥330,000/月に対し廉価版¥30,000で同等となり上位プランが崩壊する。また月¥3,000は単発チケット¥22,000の完全上位互換になる。
  - フェンスを引くなら機能側（提案書エクスポート不可、サイト追加不可、独自ドメインのメールアドレスで所有者認証 等）。
  - ※ただし現行課金モデルを全面刷新する前提なら、この警告は再設計後の体系で改めて検証すること。

## 7. 進め方の原則

- 現時点で確定できるのは骨格まで。**診断を基準単価に置き、その先を小さく刻み、上限を設けず、枠は可変にしておく。**数字の詰めは走らせてから。
- サンプル数が少ない段階では、統計より**個別ヒアリングのほうが情報量が多い**。フューチャーショップ社に「診断を配った後、次に金を払う気になるとしたら何に対してか」を直接聞けば、刻みの単位が推測抜きで決まる。
- **理由の解明を待たずに進めてよいのはハイブリッド化そのもの**（参入障壁を下げる効果は構造的に確実）。UI改修・機能絞り込みは計測結果を見てから精度を上げる。
