## 1. このサービスは何か

**これから事業をつくる人が、自分の人生の経験から「選ばれる理由」のある事業の戦略をつくる**サービス。

- 【決定】別サービス・別ドメインで出す。今の戦略指南（サイトを分析する側）とは入口も見せ方も分ける。相互リンクは置く
- 【決定】分析エンジンは今の戦略指南と共通。違うのは「何を入力にするか」：今の版はウェブサイト、新規事業版は**その人自身**（原体験・価値観・構想）
- 【決定】料金はポイント制。トライアル12,700pt（標準分析1回ぶん＋α）

### 誰が使うか
- 50代前後で、定年後や独立を見据えて「自分の経験で事業をつくりたい」人（AIオーナーシップ本の読者層）
- オンラインキャンプの受講者（10/15開始・第1期30名）
- 事業の構想はあるが、言葉にも戦略にもなっていない人

### 体験の芯
7月の結論：**その人のいいところを見つけて引き出し、まず言葉にして、その人らしい事業にする → 「自分のことを分かってくれている」と感じてもらう。**
新規事業版の体験は、この「引き出して言葉にする」を1本の流れにしたもの。

## 2. 全体の流れ

```
①はじめる → ②自己分析の取り込み（任意）→ ③ヒアリング（チャット）→ ④まとめの確認
   → ⑤分析（2〜4分）→ ⑥戦略レポート（ナラティブ入り）→ ⑦磨く（チャット・再分析）→ ⑧確定
   → ⑨その先（競合徹底分析・社名・アクション）
```

| 段階 | 画面 | ポイント |
|---|---|---|
| ① はじめる | トップ／ログイン | トライアル12,700pt付与 |
| ② 自己分析の取り込み | 取り込み画面 | 0 |
| ③ ヒアリング | チャット | 0（分析に含む） |
| ④ まとめの確認 | チャット内 | 0 |
| ⑤ 分析 | 待ち画面 | 10,000 |
| ⑥ 戦略レポート | レポート | — |
| ⑦ 磨く | レポート＋チャット | チャット100／再分析1,000 |
| ⑧ 確定 | レポート | 0 |
| ⑨ その先 | 成果物の一覧 | 競合徹底分析20,000 など |

## 3. 画面ごとの設計

### ① はじめる（トップ・ログイン）
- 伝えること：「あなたの経験から、選ばれる理由のある事業をつくる」。一般論ではなく、**あなたの話を聞いてから**戦略をつくるサービスであること
- 流れを最初に見せる（ヒアリング → 分析 → レポート）。所要時間の目安も
- Googleでログイン → トライアル12,700ptが付与されたことを伝える

### ② 自己分析の取り込み（任意）
- 【決定】村上さんの自己分析AI（AIコーチングツール）の書き出しPDFを最初に入れてもらう
- 入れる：PDFをドロップ → 読み取った章（強み・特徴／価値観／仕事の仕方）を短く表示して「この内容をもとに伺います」
- 入れない：「自己分析なしで始める」→ ヒアリングで一から聞く
- 【提案】個人的な内容（出自・家族など）が含まれるので、「このサービスの中だけで使い、いつでも削除できます」と明記。本人が削除できるようにする

### ③ ヒアリング（チャット）
- 【決定】**普通の対話型チャットだけ**（フォーム併用はしない）
- 【決定】冒頭で全体を示す：「これから5つの項目について伺っていきます」
  1. 事業をやろうと思ったきっかけ・原体験
  2. 解決したい課題
  3. 想定しているお客様
  4. 商品・サービスのイメージ・構想
  5. それによってお客様が得られるもの
- 【決定】1項目ずつ聞く。抽象的なら具体を、具体的すぎれば抽象を求め、足りない項目だけ掘り下げる
- 【決定】自己分析を入れた人：1〜3章（強み・価値観・仕事の仕方）を①②のベースにして、聞き直さずに「つなげる質問」をする。③〜⑤は改めて聞く
- 【決定】自己分析4章の案A・案Bは、たたき台にせず**参考として言及する**。本人は読んでいるので、競合・市場を調べたうえで講評する（例：「案Aのような考え方もありますが、実は競合が非常に多いため、あまりお勧めできません」）。→ ヒアリング中にAIがウェブ検索を使える
- 【決定】長さの目安は置かない（自己分析そのものに30分〜2時間かかる人もいる）
- 今どこにいるかは、AIが言葉で区切る（「では②に移ります」）
- 【決定】進み具合の表示（例「② 解決したい課題（2/5）」）は、**無理なく出せるなら出す。ノイズになるなら出さない**（2026-09-23 権さん）。デザインで判断する
- 【提案】途中で離れても、戻れば続きから再開できる

### ④ まとめの確認（チャット内）
- 【決定】最後に5項目を整理して見せ、「変えたいところはありますか」ともう一度聞く
- 直したいところは、チャットで伝えれば直る
- 「この内容で分析する（10,000ポイント）」ボタン。**使うポイントを押す前に見せる**

### ⑤ 分析（2〜4分）
- 待ち時間が長い（実測で約3分）。何をしているかを段階で見せる：「競合を調べています」「市場の大きさを調べています」「戦略を組み立てています」
- 【提案】待っている間に、④のまとめを読み返せるようにする

### ⑥ 戦略レポート
- 【決定】**戦略ナラティブを入れる**
- 【決定】ナラティブは**分析と同時に書く**。チャットで戦略を磨いて版が変われば、**ナラティブもその版に合わせて書き直す**（版ごとにナラティブを持つ）（2026-09-23 権さん）
- 【提案】構成（上から）：
  1. **戦略メッセージ**（20〜30字）— 一番大きく
  2. **戦略ナラティブ**（500〜1000字の一人語り）— 「なぜこの事業か、誰のために、何を約束するか」を本人の声で
  3. **AB3C** — ベネフィット（赤）・アドバンテージ（青）・3C（黒）
  4. **3つのパターン**の比較（お勧めのパターンに印）
  5. **自己分析の案A・案Bへの講評**（取り込んだ人だけ）
  6. **次の一歩**
- 戦略の階層：社名（数文字）← 戦略メッセージ（20〜30字）← 戦略ナラティブ（500〜1000字）← 実装物（ウェブ・営業資料・LP）。レポートはこの階層が上から見える形

### ⑦ 磨く
- レポートを読みながら、チャットで「ここは違う」「もっとこうしたい」を伝える
- 各項目から直接チャットに質問を送れる（今の戦略指南の💬と同じ）
- 反映は再分析（1,000ポイント）

### ⑧ 確定
- 「この戦略で進める」で確定。確定した版は残り、いつでも戻れる

### ⑨ その先（成果物の一覧）
- 【提案】確定後に、次にできることをカードで並べる：競合徹底分析（20,000pt）／社名・店名の案／ウェブサイトの叩き台／営業資料 など
- 各カードに「何ポイント使うか」を表示

### 共通：ポイントの見せ方
- 画面の隅に**残りポイント**を常に表示
- ポイントを使う操作は、押す前に消費量を見せる
- 足りないときは購入画面（/points）へ案内

## 4. Claude Design への依頼文（叩き台）

以下をそのまま Claude Design に渡す想定。**色は過剰に指定しない**（センスを見たい要素は任せる）。守ってほしいルールだけを明記する。

---

> **依頼：新規事業向けの戦略策定サービスの画面デザイン**
>
> ### サービスの概要
> これから事業をつくる人が、自分の人生の経験から「選ばれる理由」のある事業の戦略をつくるサービスです。AIがインタビュアーとして話を聞き、競合と市場を調べたうえで、戦略レポートを書きます。一般論を量産するAIではなく、「あなたの話を聞いてから、あなただけの戦略をつくる」ことが価値の中心です。
>
> 主な利用者は50代前後で、定年後や独立を見据えて自分の経験で事業をつくりたい人です。ITに詳しいとは限りません。
>
> ### つくってほしい画面
> 1. **トップ**：サービスの約束と、ヒアリング → 分析 → レポートの流れ。「無料で始める（Googleでログイン）」
> 2. **自己分析の取り込み**：PDFをドロップする画面。「自己分析なしで始める」も選べる。個人的な内容を扱うことへの安心感
> 3. **ヒアリング（チャット）**：AIが5つの項目を順に聞く対話画面。普通のチャットとして自然に見えること。今どの項目かを示す表示は、うるさくならずに出せるなら出す。ノイズになるなら無くてよい（その判断もお任せします）
> 4. **まとめの確認**：チャットの中に、5項目の整理が1枚のカードとして出る。「この内容で分析する（10,000ポイント）」と「直したいところを伝える」
> 5. **分析中**：約3分の待ち。何をしているかが段階で分かる
> 6. **戦略レポート**：戦略メッセージ → 戦略ナラティブ（一人語りの文章）→ AB3C → 3つのパターン → 次の一歩。レポートを読みながら、横でチャットができる。チャットで戦略を磨くと版（v1, v2…）が増え、ナラティブも版ごとに書き直される。どの版を読んでいるか、確定しているのはどの版かが分かること
> 7. **確定後の成果物の一覧**：次にできることをカードで並べる。各カードに使うポイントを表示
>
> ### 体験として大事にしたいこと
> - **「自分のことを分かってくれている」と感じる**こと。フォームに記入させられる感じではなく、話を聞いてもらっている感じ
> - 戦略ナラティブは、このサービスの一番の成果物。**本人の声で書かれた手紙のように**読めること
> - 待ち時間や費用（ポイント）で不安にさせない。使う前に何ポイントかを見せる
>
> ### 守ってほしいルール
> - **色の意味は固定**：ベネフィット＝赤 #FF0000、アドバンテージ＝青 #1a6fd4、3C（顧客・競合・自社）＝黒 #1a1a14。AB3Cを表す部分だけに使い、装飾には使わない。他の配色はお任せします
> - **文字は大きく**：本文18px、最小16px。16px未満は使わない
> - **本文はゴシック体**、見出しだけ明朝（Noto Serif JP）可
> - ベージュの多用、グラデーションの装飾は避ける（AIが作った感じが出るため）
> - 画面上の文言はすべて日本語。英単語のラベル（OK・NG以外）は使わない
>
> ### サンプルの中身（架空の人物）
> 52歳・メーカーで30年営業をしてきた人。地方の町工場が、技術はあるのに売り方を知らずに廃業していくのを見てきた。町工場の技術を、個人の作り手や小さなブランドにつなぐ事業を考えている。
> - 戦略メッセージの例：「町工場の技術を、あなたのものづくりに。」
> - ナラティブの書き出しの例：「30年、町工場を回ってきました。技術はあるのに、売り方を知らないまま看板を下ろす工場を、何社も見送ってきました。」
